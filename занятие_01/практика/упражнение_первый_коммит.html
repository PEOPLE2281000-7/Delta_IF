    Упражнение: первый коммит

    Что делаем: создаём репозиторий и делаем первые коммиты проекта «Генератор паролей». Инструмент: VS Code, панель «Источник» (Source Control).

    Готовые варианты кода лежат в папке практики: 01_password_letters.py … 04_password_save.py. Лучше печатай код сам — так запомнишь, что куда идёт.

    Шаг 1. Папка проекта

    Создай папку, например C:\tt\password-gen (или ~/password-gen), и открой её в VS Code (Файл → Открыть папку).

    Шаг 2. Создаём репозиторий

    1. Открой вкладку «Источник» (Ctrl+Shift+G).
    2. Нажми «Initialize Repository» — git включился для этой папки.

    Шаг 3. Пароль из букв — первый коммит

    Создай файл main.py:

    import random
import string

print("=== Генератор паролей ===")

length = int(input("Длина пароля: "))
password = "".join(random.choice(string.ascii_letters) for _ in range(length))
print(f"Твой пароль: {password}")

    Запусти: python main.py. Пароль печатается — работает.

    Во вкладке «Источник»: нажми + у main.py, напиши сообщение добавил генерацию пароля из букв, нажми ✓ Commit.

    Шаг 4. Цифры и символы — второй коммит

    См. 02_password_symbols.py. Изменение одно — в наборе символов:

    chars = string.ascii_letters + string.digits + string.punctuation
password = "".join(random.choice(chars) for _ in range(length))

    Запусти — теперь в пароле есть цифры и символы. Коммит: добавил цифры и символы в пароль.

    Шаг 5. Выбор набора символов — третий коммит

    См. 03_password_choice.py. Добавь меню и выбор набора (1 — буквы, 2 — буквы и цифры, 3 — всё):

    ALPHABETS = {
    "1": string.ascii_letters,
    "2": string.ascii_letters + string.digits,
    "3": string.ascii_letters + string.digits + string.punctuation,
}

    Запусти и проверь все три набора. Коммит: добавил выбор набора символов.

    Шаг 6. Сохранение в файл — четвёртый коммит

    См. 04_password_save.py. Добавь функцию сохранения:

    def save_password(password):
    """Дописывает пароль в файл passwords.txt."""
    with open("passwords.txt", "a", encoding="utf-8") as f:
        f.write(password + "\n")

    И после вывода пароля спрашивай про сохранение:

    if input("Сохранить в файл? (д/н): ").strip().lower() == "д":
    save_password(password)
    print("Пароль сохранён в passwords.txt.")

    Запусти, сохрани пароль. Проверь: файл passwords.txt появился в папке и в списке Changes. Коммит: добавил сохранение паролей в файл.

    Шаг 7. Мусор и .gitignore — пятый коммит

    Запусти программу ещё раз. В Changes появилось __pycache__/ (байт-код Python) — этому в git не место. Создай в корне проекта файл .gitignore:

    # байт-код Python
__pycache__/

# личные данные пользователя
passwords.txt

    После сохранения мусор исчез из «Источника». Коммит: docs: добавил .gitignore.

    Шаг 8. «Сломай и верни» (не закоммичено!)

    1. В main.py замени одну строку на ерунду (например, убери print из меню), сохрани.
    2. В «Источнике» увидишь изменение — открой его и посмотри diff: исчезнувшая строка подсвечена красным, добавленная — зелёным.
    3. Нажми Discard у файла — правка отменилась, код вернулся.
    4. Запусти программу: всё снова работает. Ни одна версия не потеряна.

    Шаг 9. Смотрим историю

    Во вкладке «Источник» — список коммитов. Кликни по любому и посмотри, что изменилось именно в нём. Поздравляю — твой проект под контролем версий!

    Чек-лист упражнения

    • [ ] Репозиторий создан, в истории 5 коммитов
    • [ ] Каждый коммит — работающая версия программы
    • [ ] Сообщения осмысленные, используются префиксы feat/docs
    • [ ] Diff и Discard проверены на «сломанной» строке
    • [ ] passwords.txt и __pycache__ исчезли из Changes благодаря .gitignore

    Если застрял

    • «Кнопки Initialize Repository нет» — папка уже репозиторий (значит, ты это делал). Продолжай с шага 3.
    • Git просит имя и почту — введи один раз: git config --global user.name "Имя" и git config --global user.email "mail@x.y".
    • Discard отменил мои правки, а я не хотел! — Discard отменяет только незакоммиченное. Закоммиченная история всегда на месте.
    • .gitignore не работает — проверь, что он лежит в корне проекта и имя с точкой: .gitignore.
