# Краткий курс «Git для проектов» — материалы ученика

Привет! Это материалы модуля **«Git для проектов»** курса «Проектное
программирование на Python». Всё открывается в браузере — интернет для чтения
не нужен.

## Что внутри
- `index.html` — главная страница с навигацией по занятиям. **Открой её двойным
  кликом в браузере.**
- Слева — меню: конспект, шпаргалка и практика каждого занятия.
- В поле поиска можно искать по всем материалам сразу.

## Занятия
1. **Первый коммит** — репозиторий, коммиты, diff, `.gitignore`, откаты.
2. **Ветки и слияния** — фича-ветки, merge, конфликты, публикация в облако.
3. **Командная работа** — clone, общий репозиторий, форк и pull request.
4. **Команды в терминале** — те же операции словом.

Сквозной проект — консольный **«Генератор паролей»** (Python 3.10+).

## Первый запуск
1. Установи **git** (если ещё нет) и один раз настрой имя и почту — как показано
   на занятии:
   ```
   git config --global user.name  "Твоё Имя"
   git config --global user.email "tvoya@pochta.ru"
   ```
2. Открой `index.html` и переходи по ссылкам на занятие 1.
3. Открой папку проекта в VS Code и запусти первый пример из практики.

## Как получать обновления
Учитель выдаёт новую карточку (обновлённый набор файлов). Открой новый
`index.html` — навигация обновится.

Вопросы — учителю :)
